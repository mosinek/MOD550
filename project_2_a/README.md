The dataset contains information about the daily weather conditions in Stavanger, Norway. 
The columns of the datasets are:

- Temperature: daily average temperature measurement (per day) - numerical [Celcius]
- Wind speed: daily average wind speed measurement - numerical [m/s]
- Air pressure: daily average air pressure measurement  - numerical [hPa]
- Rainfall: daily average rainfall measurement  - numerical [mm]
- Humidity: daily average humidity measurement - numerical [%]
- Cloud coverage: daily "most observed" cloud coverage in Stavanger - categorical ["Clear", "Cumulus", "Cirus", "Cumulonimbus", "Stratus"]
